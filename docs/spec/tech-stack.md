# 技術スタック（2026-11-23）

技大祭 落とし物管理システムの技術スタック

## 構成

ミニマム版は、来場者と実行委員がスマートフォンのブラウザーで利用するWebアプリケーションとする。画面とAPIは一つのNext.jsプロジェクトにまとめ、Next.jsとPostgreSQLをDocker Composeで起動する。

| 項目 | 採用技術・方式 |
|---|---|
| 画面 | Next.js App Router。ReactとTypeScriptで来場者向け・実行委員向けの画面を実装する。スタイルはCSS Modulesで管理する。 |
| API | Next.js Route Handlers。QR読み取り後の仮登録、回収、本登録、紛失の届け出、受渡の処理を実装する。 |
| データベース | PostgreSQL。ボックス、拾得物とその状態、紛失の届け出、受渡記録を保存する。 |
| DB操作 | Next.jsのサーバー側から`pg`（node-postgres）でパラメータ付きSQLを実行する。テーブル定義の変更は連番付きのSQLファイルで管理する。開発時の確認には`psql`を使う。 |
| 写真 | 写真本体はDockerの永続ボリュームに保存し、DBにはファイルの識別子を記録する。閲覧時はNext.js側で公開範囲を確認する。 |
| 実行委員の認証 | 共通パスコードでログインし、Cookieでセッションを維持する。管理操作と受渡記録の閲覧時に、サーバー側で権限を確認する。 |
| メール | Next.jsからSMTP経由で、照合後の落とし主に保管場所と管理番号を送る。SMTPの接続先は別途決める。 |
| 実行環境 | Docker Composeで`app`（Next.js）と`db`（PostgreSQL）を起動する。DBはComposeの内部ネットワークから接続し、DBデータと写真はそれぞれ永続ボリュームに保存する。本番のブラウザー接続にはHTTPSを使う。 |
